# assets — изображения для стадии генерации презентации Telepath

Сюда нужно положить два PNG, которые агент использует при создании 3-слайдовой .pptx
(стадия `presentation` в orchestrator.py). Имена файлов фиксированы — стадия ищет их
по точным путям:

```
D:\lead_gen\lead_orchestrator\assets\citrt_logo.png       — логотип АО «ЦИТ РТ» (прозрачный фон желательно)
D:\lead_gen\lead_orchestrator\assets\bulat_zamaliev.png   — фото Булата Замалиева
```

Что делает агент сам:
- логотип — раскладывает по фирстилю (на тёмных слайдах на белой скруглённой подложке);
- фото Булата — кадрирует в портрет, убирает посторонний фон/цветовые пятна по краям, скругляет углы.

Если хотя бы одного файла нет — стадия презентации ПРОПУСКАЕТСЯ с предупреждением в лог,
а остальной конвейер (два .docx) отрабатывает как обычно.
