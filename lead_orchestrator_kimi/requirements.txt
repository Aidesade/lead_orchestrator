# ⚠️ Кука кодировки выше обязана быть В ПЕРВЫХ ДВУХ СТРОКАХ. Без неё pip на Windows читает файл
# локальной кодировкой (cp1251) и падает с UnicodeDecodeError на кириллице в комментариях: BOM
# нет, и pip.auto_decode ищет ровно такую PEP-263 куку, иначе берёт локаль. В Linux/Docker
# локаль UTF-8, поэтому ломалась бы ТОЛЬКО локальная установка — там, где её и делают руками.

# ==========================================================================================
# Лок изолированного окружения стадии one-pager (.venv_kimi). Python 3.12.
#
# ⚠️ ПОЧЕМУ ИМЕННО kimi-cli 1.12.0 И НЕ ВЫШЕ.
# `kimi-agent-sdk` застыл на 0.0.5 (альфа) и объявляет `kimi-cli>=1.12.0,<1.13.0`. Он зовёт
# `KimiCLI.create(..., skills_dir=...)` — имя параметра из 1.12.x. В kimi-cli >=1.4x параметр
# переименован в `skills_dirs` (список), и SDK 0.0.5 туда уже не попадает.
# Раньше в .venv_kimi стоял kimi-cli 1.48.0 (его подняли руками, вне заявленной границы), а
# рассинхрон закрывали ВТОРЫМ патчем прямо в site-packages. Это лишняя поломка на ровном месте:
# 1.12.0 поддерживает кастомный провайдер (KIMI_BASE_URL / KIMI_API_KEY / KIMI_MODEL_NAME)
# ровно так же, как 1.48.0, — проверено по исходникам обеих версий. Поэтому фиксируем ПАРУ,
# которую SDK сам объявляет совместимой: патч №2 не нужен, pip ставит без конфликтов и без
# --no-deps, остаётся один патч №1 (баг Python 3.12).
#
# ⚠️ НЕ ПОДНИМАТЬ kimi-cli, не обновив kimi-agent-sdk. `pip install --upgrade kimi-cli` вернёт
# ту самую поломку. Если SDK когда-нибудь выйдет из 0.0.5 — пересмотреть эту пару целиком.
#
# ⚠️ ОКРУЖЕНИЕ ОТДЕЛЬНОЕ ОТ ОСНОВНОГО. В один интерпретатор kimi и claude-agent-sdk не ставятся:
# kimi тянет pydantic-core 2.41.5, а claude-agent-sdk/anthropic требуют 2.46.4. Глобальная
# установка ЛОМАЕТ рабочий lead_orchestrator/ (уже случалось — см. README).
#
# Установка (из папки lead_orchestrator_kimi):
#   py -m venv .venv_kimi
#   .venv_kimi\Scripts\python.exe -m pip install -r requirements.txt
#   .venv_kimi\Scripts\python.exe patches\apply_patches.py     # ОБЯЗАТЕЛЬНО: иначе import падает
#
# ⚠️ Любая переустановка пакетов СТИРАЕТ патч — apply_patches.py прогонять снова. Он идемпотентен
# и сам определяет, какие патчи нужны установленной версии kimi-cli.
# ==========================================================================================
