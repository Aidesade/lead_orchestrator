# Готовые one-pager'ы по отраслям

Сюда кладутся заранее подготовленные PDF, которые outreach-пайплайн прикладывает к письму
(стадия 3). Имя файла — **ключ отрасли из `source_rusprofile.INDUSTRY`** плюс `.pdf`:

```
mining.pdf          # Добыча полезных ископаемых
energy.pdf          # Производство и распределение электроэнергии, газа и воды
processing.pdf      # Промышленная переработка
...
default.pdf         # запасной вариант, если под отрасль файла нет
```

Полный список из 21 ключа — `py -c "import source_rusprofile as R; print(*sorted(R.INDUSTRY))"`.

Правила, которые проверяет код (`outreach.stage_onepager`):

* берётся `<отрасль>.pdf`, затем `default.pdf`;
* файл меньше **60 КБ** считается заготовкой и НЕ прикладывается — это тот же порог,
  по которому резюм основного оркестратора отличает реальный one-pager от болванки;
* если подходящего файла нет, письмо уходит **без вложения**, а стадия попадает в реестр
  как пропущенная с причиной — компания из-за этого не теряется.

Сгенерировать one-pager под конкретную компанию вместо готового файла:
`py outreach.py … --generate-onepager` (запускает существующую стадию
`../lead_orchestrator_kimi/onepager_kimi.py`).

Путь к папке переопределяется переменной `OUTREACH_ONEPAGER_DIR`.

Сами PDF в git не коммитятся — они большие и меняются отдельно от кода.
